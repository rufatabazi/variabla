Variabla, funksioni dhe struktura ne C++

1. Cfare eshte variabla?

Variabla eshte nje vend ne kompjuter ku e ruajme nje vlere. Mund ta mendojme si nje kuti qe ka nje emer. Brenda kutise e vendosim vleren.

Shembull: kutia me emrin mosha ka brenda numrin 15.

mosha

15

3. Pse quhet variabel?

Quhet variabel sepse vlera mund te ndryshoje. Per shembull:

int mosha = 15;
mosha = 16;

Ne fillim kutia ka 15, pastaj e ndryshojme dhe ka 16. Emri mbetet po ai, ndryshon vetem vlera. Kur e ndryshojme nuk shkruajme me "int", sepse variabla eshte krijuar tashme.

Pamja me shigjeta: variabla ndryshon

15
mosha = 16;→
mosha
16

Kutia ka te njejtin emer, por vlera e vjeter (15) shkon dhe vjen vlera e re (16).

5. Cfare eshte funksioni?

Funksioni eshte nje pjese kodi qe ka nje emer dhe ben nje pune te caktuar. Kur na duhet ajo pune, thjesht e thirrim funksionin me emrin e tij. Keshtu nuk e shkruajme te njejtin kod disa here.

Mund ta mendojme si nje makine: i japim disa gjera (hyrjen), ajo punon, dhe na kthen nje rezultat (daljen).

Shembull: funksion qe mbledh dy numra.

int mbledh(int a, int b) {
    int shuma = a + b;
    return shuma;
}

Pjeset e funksionit:

Parametrat int a, int b Vlerat qe i japim funksionit. Jane variabla qe ekzistojne vetem brenda funksionit
Trupi { ... } Kodi qe ekzekutohet kur thirret funksioni
return return shuma; Kthen rezultatin dhe e mbyll funksionin

Si e thirrim funksionin:

int rezultati = mbledh(5, 3);

Ketu 5 shkon te a, 3 shkon te b, funksioni i mbledh dhe kthen 8. Pastaj numri 8 ruhet ne variablen rezultati.

Funksioni pa rezultat quhet void. Ai vetem ben nje pune dhe nuk kthen asgje: 

void pershendet() {
    cout << "Pershendetje!" << endl;
}

Lidhja me variablat: variabla e krijuar brenda funksionit (si shuma) ekziston vetem brenda tij. Jashte funksionit nuk mund ta perdorim. Kjo quhet variabel lokale.

6. Cfare eshte struktura?

Struktura (struct) na lejon te bashkojme disa variabla ne nje grup te vetem. Variablat brenda struktures mund te jene te llojeve te ndryshme.

Per shembull, nje student ka emer, moshe dhe note. Ne vend qe t'i bejme tre variabla te ndara, i bashkojme ne nje strukture te quajtur Student. 

struct Student {
    string emri;
    int mosha;
    double nota;
};

Struktura si kuti qe ka kuti brenda:

Student

emri: "Arben"
mosha: 15
nota: 9.5

Kujdes: ky kod vetem e pershkruan strukturen, si nje skice. Per ta perdorur duhet te krijojme nje variabel te llojit Student: 

Student s1;
s1.emri = "Arben";
s1.mosha = 15;
s1.nota = 9.5;

Pika (.) perdoret per te hyre ne nje pjese te struktures. s1.mosha do te thote "mosha e studentit s1".

Pamja me shigjeta: struktura s1

Si e shkruajme Cfare ruan
s1.emri → "Arben"
s1.mosha → 15
s1.nota → 9.5

Struktura (Student) → variabla (s1) → pjeset e saj (emri, mosha, nota).

7. Nje program i plote qe i bashkon te gjitha

#include <iostream>
#include <string>
using namespace std;

// struktura
struct Student {
    string emri;
    int mosha;
    double nota;
};

// funksion qe kthen rezultat
int mbledh(int a, int b) {
    int shuma = a + b;
    return shuma;
}

// funksion qe merr nje strukture dhe e shfaq
void shfaqStudentin(Student s) {
    cout << "Emri: " << s.emri << endl;
    cout << "Mosha: " << s.mosha << endl;
    cout << "Nota: " << s.nota << endl;
}

int main() {
    // variabla
    int x = 5;
    int y = 3;

    // thirrja e funksionit
    int rezultati = mbledh(x, y);
    cout << "Shuma: " << rezultati << endl;

    // variabel e llojit struktura
    Student s1;
    s1.emri = "Arben";
    s1.mosha = 15;
    s1.nota = 9.5;

    shfaqStudentin(s1);

    return 0;
}

Programi shfaq:

Shuma: 8
Emri: Arben
Mosha: 15
Nota: 9.5

Perfundim

Variabla ruan nje vlere dhe ka nje emer dhe nje lloj. Funksioni eshte kod me emer qe e thirrim kur na duhet, dhe mund te ktheje rezultat. Struktura bashkon disa variabla ne nje grup te vetem. Ne C++ duhet gjithmone ta shkruajme llojin kur e krijojme variablen.
