Variabla ne C++

Çfare eshte variabla?

Variabla eshte nje vend ne kompjuter ku e ruajme nje vlere. Mund ta mendojme si nje kuti qe ka nje emer. Brenda kutise e vendosim vleren.

Shembull: kutia me emrin mosha ka brenda numrin 15.

mosha

15

Si shkruhet ne C++

int mosha = 15;

int - lloji i variables (numer i plote)
mosha - emri i variables
= - e vendos vleren ne kuti
15 - vlera
; - çdo rresht ne C++ mbaron me pikepresje

Pse quhet variabel?

Quhet variabel sepse vlera mund te ndryshoje. Per shembull:

int mosha = 15;
mosha = 16;

Ne fillim kutia ka 15, pastaj e ndryshojme dhe ka 16. Emri mbetet po ai, ndryshon vetem vlera. Kur e ndryshojme nuk shkruajme me "int", sepse variabla eshte krijuar tashme.

Llojet e variablave ne C++

Lloji Çfare ruan Shembull
int numer i plote int nota = 10;
double numer me presje double cmimi = 9.5;
char nje shkronje char shkronja = 'A';
string tekst string emri = "Arben";
bool true ose false bool jeStudent = true;

Nje program i plote

#include <iostream>
using namespace std;

int main() {
    int mosha = 15;
    cout << "Mosha ime eshte " << mosha << endl;

    mosha = 16;
    cout << "Tani mosha eshte " << mosha << endl;

    return 0;
}

Programi shfaq:

Mosha ime eshte 15
Tani mosha eshte 16

Perfundim

Variabla ruan nje vlere dhe ka nje emer dhe nje lloj. Ne C++ duhet gjithmone ta shkruajme llojin kur e krijojme variablen. Vlera e saj mund te ndryshoje gjate programit.
